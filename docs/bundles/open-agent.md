# What is still wrong that a lane can take

Nothing. A bundle is a world value a `# flag` marked `bundle` holds: a line that
yields is bound on the line that writes it, `<bundle> = take: everything`, and poured
back with `give: everything in <bundle>`, which moves what fits and leaves the rest
standing. `count.<bundle>` is the only reading. What is still open about bundles is
the one call in `open-human.md`, and it waits on a module wanting one read rather
than moved.
